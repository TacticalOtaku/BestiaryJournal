# История изменений

## 0.2.4

### Безопасность и честность данных
- Ступени знания действуют во всём интерфейсе: библиотека, коллекция, быстрый просмотр, фильтры, поиск и сортировка больше не показывают имя, портрет, тип, ПО, КД и хиты сверх того, что открыто зрителю. Эти данные не попадают даже в скрытые атрибуты страницы.
- Бросок исследования проверяет мастер. Игрок бросает штатную проверку dnd5e, мастер сверяет сообщение в чате (автор, владелец персонажа, навык, свежесть, однократность), сам считает сложность и результат и публикует итог. Клиент больше не может сообщить «успех» или обойти режим одной попытки.
- Запрос игрока к мастеру гасится после обработки, повтор сокет-сообщения игнорируется: чужую команду нельзя выполнить повторно.
- «Отправить в чат» и итог исследования в чате показывают только то, что знает отправитель: неизвестное существо уходит силуэтом без имени.
- Обмен знанием принимает только игроков мира; заметки и обмен работают только для существ бестиария, доступных автору.
- Скрытие коллекции или существа сразу действует и на уже открытые у игроков окна.

### Исправления
- Кнопка бестиария снова появляется в шапке вкладки «Журналы» (хук Foundry v13+).
- Биография берётся из основного текста, если публичная версия не заполнена.
- Массовый импорт из актёров мира: список снова прокручивается, кнопка «Импортировать» не уезжает за край окна; загрузка показывает индикатор.
- «Копировать в мир» использует штатный импорт из компендиума и узнаёт уже скопированных актёров по источнику, а не по имени.
- Редактор записи не теряет несохранённые правки при смене источника изображения и больше не превращает автоматический навык в явный.
- Панель исследования и сам бросок берут сложность из одной и той же записи.
- Редактирование заметки можно отменить; смена канала отменяет редактирование.
- Подписи времени активации и типов предметов больше не показывают сырые ключи локализации; особая скорость существа выводится в карточке.
- Импорт JSON: «заменить» сохраняет заблокированные коллекции, «дополнить» сопоставляет коллекции сначала по id, повторяющиеся id и существа исправляются. Перед применением показывается, что будет объединено, создано и удалено.
- Экспорт одной коллекции архивирует знания только о её существах.
- Все действия сообщают об ошибке (нет мастера, таймаут, блокировка) вместо тихого отказа.

### Интерфейс
- Навигация: «Обзор», «Все существа» (по имени), «Недавние», «Избранное». Поиск в обзоре ищет по всем существам.
- Раскладка подстраивается под ширину окна, а не монитора; в узком окне боковая панель сворачивается в полосу иконок, быстрый просмотр выезжает поверх списка.
- Исправлено: бейдж фильтров с «0», съезжающие строки списка без бейджа знаний, отступы редактора коллекции и диалогов, залипающая подсветка перетаскивания, полоска закрытой панели просмотра, рассинхрон свёрнутых семейств, фон открытых фильтров, тёмная тема окна.
- Поиск, выбранное существо и прокрутка панелей сохраняются при обновлениях от других игроков.
- Заголовки окон обновляются при смене коллекции и открытии имени.
- Контекстное меню закрывается по Esc, прокрутке и потере фокуса, работает с клавиатуры; карточки действий раскрываются с клавиатуры.

### Производительность
- Данные существ кэшируются и пересчитываются только при изменении актёра или его предметов; актёры загружаются параллельно.
- Обновления объединяются, а окна перерисовываются только при изменениях, которые их касаются. Двойные перерисовки после каждого действия убраны.

### Для разработчиков
- Удалены устаревшие вызовы: `enrichHTML({ async })`, позиционный `rollSkill`, глобальные `FilePicker` и `saveDataToFile`, `render(true)`.
- Новые модули: `research-authority.mjs`, `creature-cards.mjs`, `creature-cache.mjs`, `command-feedback.mjs`.
- Тесты store с имитацией Foundry: повтор и подмена запросов, проверка бросков.

### Известное ограничение
- Мировые настройки Foundry доступны всем клиентам, поэтому игрок с консолью может прочитать чужие знания и заметки. Подробности в README.
